# 参考图学习

当用户提供其他文创、商品、包装或陈列图时，学习其设计方法，不复刻成品。参考图不是授权素材，也不是要求生成近似商品。

## 六层拆解

逐张或按组记录以下内容：

1. **品类角色**：引流小物、常销纪念品、穿戴传播款、日用实用品、收藏重点款或礼赠款；
2. **主体转化**：主体进入轮廓、结构、材料、功能、动作还是叙事；
3. **材料工艺**：纸张、金属、陶瓷、织物、木材、透明材料如何决定视觉和触感；
4. **结构互动**：异形、镂空、铰链、摆动、垂坠、折叠、拼装、透光、盖印或可替换；
5. **包装陈列**：底卡、吊牌、套封、信封、票根、编号、组合陈列如何支持产品；
6. **系列逻辑**：同一母题如何跨纸品、配饰、织物、家居和旅行用品延展，同时保持功能差异。

## 可迁移的方法

- **产品＋包装一体化**：小产品与底卡共同讲清身份、姿态和使用场景；包装不是把同一插画再印一次。
- **纸品收藏系统**：邮票、票根、明信片、信封、折页、编号和印章可以共享网格与识别系统，形成低成本系列。
- **材料专属表达**：金属适合镂空、铰链、链坠和珐琅；陶瓷适合异形边缘、浅浮雕与釉色；织物适合连续纹样、提花和折叠后构图；木材适合榫插与浅雕。
- **跨场景产品矩阵**：同一主题可进入首饰、丝巾、包袋、杯具、香氛、镜子、桌面用品和旅行用品，但不能只是换载体印同一张图。
- **情绪与日常表达**：轻文案可以增强小物的陪伴感，但应放在产品或包装逻辑中；概念图底部信息区仍只保留名称与基础材质。
- **层级与悬浮感**：深浮雕、前后层、框景、垂坠和透明叠层可以突出主体，但应匹配真实材料和装配方式。

## 禁止近似复制

不得直接沿用参考图的：

- 角色姿势、表情、轮廓和配饰组合；
- 单张插画、摄影构图和装饰纹样；
- 主辅色比例、边框、网格和文字位置；
- 商品名称、标语、情绪文案和系列命名；
- 包装开窗、吊牌或底卡的独特外形；
- 品牌标志、字体识别和可识别商业装潢。

若新方案离开参考图后不能独立解释其主体来源、功能和工艺，说明仍在模仿，应退回主体识别卡重新设计。

## 转化输出

完成学习后只保留一份抽象结论，例如：

```text
参考方法：产品与包装底卡共同叙事；金属使用镂空和活动连接；纸品形成票根收藏系统；系列覆盖穿戴、桌面和旅行场景。
本次原创转化：从当前主体的轮廓、动作和地域故事重新建立结构、配色与文案，不沿用任何参考商品的具体外观。
```

不要把参考图品牌名或商品名写入生成提示词；只有在需要明确禁止相似时，才作为 avoid 约束描述其可识别特征。
