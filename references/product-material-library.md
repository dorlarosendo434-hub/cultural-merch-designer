# 48 种产品与材质组合库

这是方案生成的选型空间，不是固定菜单。先根据主体识别卡、预算、批量、渠道和受众排除不适合项，再建立候选池。不得照搬案例产品的具体造型、纹样或构图。

## 使用方法

1. 先选与主体结构真正匹配的产品家族，而不是先选冰箱贴。
2. 多款方案中，同一主材默认不超过两款；磁吸与悬挂类合计默认不超过两款。
3. 任意两款必须在 `产品家族 / 主材 / 工艺 / 结构互动 / 使用场景` 中至少三个维度不同。
4. 若只是颜色、图案或地名变化，作为同一产品的 SKU 变体，不单独计数。
5. 成本为相对层级；最终取决于尺寸、数量、开模、包装、装配和供应商报价。
6. 异形不是默认选项。纸品、票卡、书签、拼图和包装先评估标准规格；只有轮廓识别或结构互动确有需要时才选择异形，并把刀模、排版损耗和包装成本计入判断。

## 案例学习结论

- 中国国家博物馆凤冠 IP 已扩展到家居、配饰、文具等 70 余款，说明系列需要跨场景矩阵，而不是在同一载体上持续换图案：<https://www.chnmuseum.cn/zx/gbxw/202602/t20260228_278220.shtml>
- 北京市文物局汇总的代表产品同时采用 3D 树脂、木质、金属等不同材料，证明核心纪念品也应形成材料梯度：<https://wwj.beijing.gov.cn/bjww/362679/362680/642963/436358051/>
- 湖北文博评选覆盖竹质套尺、拼图、卧香炉、盲盒、胸针、可动明信片和礼盒，说明低成本纸品、实用品与互动产品可以处于同一产品线：<https://wlt.hubei.gov.cn/bmdt/xydt/202305/t20230515_4663226.shtml>
- 河南博物院的考古盲盒和传拓盲盒把文化内容转化为操作过程，互动价值来自行为而不只是复杂外壳：<https://zhuanti.mct.gov.cn/hnbwy2022/2750.html>、<https://zhuanti.mct.gov.cn/hnbwy2022/2759.html>
- 故宫绿色文创使用回收环保材质制作风衣、丝巾、手绳和雨伞，提供了材料与生活方式同步扩展的案例：<https://www.mct.gov.cn/whzx/zsdw/ggbwy/202609/t20260911_967118.html>
- 淄博陶瓷琉璃博物馆使用 AR 冰箱贴，把数字内容作为附加层；数字增强应建立在主体准确、实体产品成立的基础上：<https://www.sdxc.gov.cn/whql/whqlsy/202601/t20260119_17320688.htm>

这些案例只用于归纳产品家族、材料路径和互动方式，不复制其具体 IP、外观和故事。
