# 结构与量产

先找到主体能转化成什么结构，再选择产品载体。不要从“冰箱贴、钥匙扣、杯垫”的清单反推设计。

## 常用转化方式

| 主体特征 | 可转化结构 | 常用材料 |
| --- | --- | --- |
| 强轮廓 | 异形裁切、镂空、正负形 | 亚克力、金属、木材、陶瓷 |
| 花瓣、毛发、岩层、服饰层级 | 浅浮雕、高浮雕、分层叠片 | 树脂、软胶、压铸金属、透明亚克力 |
| 瓶子、眼睛、窗洞、水体 | 透明腔体、流沙、透光、液体 | 透明树脂、PC、亚克力、玻璃替代材料 |
| 枝条、尾巴、流苏、翅膀 | 摆动、转轴、悬挂、弹性连接 | 金属轴、链条、软胶、织物 |
| 街道、峡谷、庭院、花廊 | 多层景深、抽拉、折叠、弹出 | 亚克力、纸艺、木片、磁吸件 |
| 风帽、服装、贝壳、果皮 | 包体、收纳、保护壳、穿戴物 | 刺绣布、提花、硅胶、皮革替代材料 |
| 行为与性格 | 不倒翁、慢摆、滚动、拼合 | 配重件、轴承、磁吸、弹簧 |

## 六款组合思路

默认六款时，可以从下列方向选取互补组合，不要求固定顺序：

1. 低成本但轮廓鲜明的基础款；
2. 以主体特写或标志结构为核心的浮雕款；
3. 以完整主体为核心的 3D 收藏款；
4. 以道具或自然现象为核心的互动款；
5. 由场景空间转化的分层款；
6. 兼具日常用途的织物、文具或家居款。

至少有一款让主体本身成为产品体积，而不是全部停留在平面印刷。若主体天然适合立体化，可提高 3D、浮雕和光影产品的比例。

## 避免俗套

- 不用“主体照片＋地名大字＋统一白边”作为默认答案。
- 不因中国题材自动添加祥云、印章、灯笼、脸谱、古建筑或大面积金色。
- 地域感来自真实结构、场景和生活方式，不来自无依据的符号拼贴。
- 原创 IP 不用换装、加武器或改变性别来制造所谓新意，优先开发原设已有的道具、服装和动作。

## 可生产性快速检查

- 小尺寸下主体是否仍能识别；
- 细长连接是否容易折断；
- 活动件是否有可靠轴点和限位；
- 透明腔体是否过厚、过重或容易泄漏；
- 摆件重心和底座是否稳定；
- 浮雕层次是否允许脱模；
- 刺绣和织物配件是否容易勾挂；
- 复杂纹样是否需要减线、分色或改用印刷；
- 效果图里的悬浮、发光和透明结构是否真的能实现。
