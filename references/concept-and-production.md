# 结构与量产

先找到主体能转化成什么结构，再选择产品载体。不要从“冰箱贴、钥匙扣、杯垫”的清单反推设计。

## 常用转化方式

| 主体特征 | 可转化结构 | 常用材料 |
| --- | --- | --- |
| 强轮廓 | 异形裁切、镂空、正负形 | 亚克力、金属、木材、陶瓷 |
| 花瓣、毛发、岩层、服饰层级 | 浅浮雕、高浮雕、分层叠片 | 树脂、软胶、压铸金属、透明亚克力 |
| 瓶子、眼睛、窗洞、水体 | 透明腔体、流沙、透光、液体 | 透明树脂、PC、亚克力、玻璃替代材料 |
| 枝条、尾巴、流苏、翅膀 | 摆动、转轴、悬挂、弹性连接 | 金属轴、链条、软胶、织物 |
| 街道、峡谷、庭院、花廊 | 多层景深、抽拉、折叠、弹出 | 亚克力、纸艺、木片、磁吸件 |
| 风帽、服装、贝壳、果皮 | 包体、收纳、保护壳、穿戴物 | 刺绣布、提花、硅胶、皮革替代材料 |
| 行为与性格 | 不倒翁、慢摆、滚动、拼合 | 配重件、轴承、磁吸、弹簧 |

## 六款组合思路

默认六款时，优先采用下列成本结构，不要求固定品类：

1. 两款低成本纸品或平面小物；
2. 两款工艺成熟的核心纪念品；
3. 一款中成本日常实用品；
4. 最多一款用于拉开系列高度的高成本概念品。

立体化优先使用陶瓷浅浮雕、软胶、压凸、滴胶或分层亚克力等成熟方案。只有主体确实依赖体积、运动或光影才能成立时，才选择完整 3D、流沙、灯光或机械结构。

## 品类与成本层级

成本层级是相对判断，需结合尺寸、数量、开模、包装和供应商报价确认，不给未经询价的精确单价。

| 层级 | 优先品类 | 适用方式 |
| --- | --- | --- |
| 低成本、成熟 | 明信片、异形卡片、纸质书签、贴纸、纸胶带、盖章卡 | 用构图、局部UV、烫色、压凸或异形模切建立差异 |
| 低至中成本、成熟 | 亚克力/木质冰箱贴、钥匙扣、徽章、金属书签、简单杯垫 | 控制层数、配件数量和精细镂空 |
| 中成本、成熟 | 陶瓷冰箱贴、陶瓷杯垫、珐琅徽章、简单布袋、织物小包 | 适合浅浮雕、釉色、刺绣或少量配件 |
| 中高成本 | 多层亚克力、树脂浮雕、复杂布艺、礼盒组合 | 作为系列重点款，提前检查厚度、重量和装配 |
| 高成本、概念 | 完整 3D 摆件、灯具、流沙腔体、机械可动、多材料装置 | 默认最多一款，明确标注需结构打样与供应链评估 |

品类丰富不等于工艺复杂。明信片、书签和陶瓷冰箱贴也要通过主体裁切、局部构图、压凸、釉色或材质关系形成独立设计，不能直接缩放同一张图。

## 避免俗套

- 不用“主体照片＋地名大字＋统一白边”作为默认答案。
- 不因中国题材自动添加祥云、印章、灯笼、脸谱、古建筑或大面积金色。
- 地域感来自真实结构、场景和生活方式，不来自无依据的符号拼贴。
- 原创 IP 不用换装、加武器或改变性别来制造所谓新意，优先开发原设已有的道具、服装和动作。

## 可生产性快速检查

- 小尺寸下主体是否仍能识别；
- 细长连接是否容易折断；
- 活动件是否有可靠轴点和限位；
- 透明腔体是否过厚、过重或容易泄漏；
- 摆件重心和底座是否稳定；
- 浮雕层次是否允许脱模；
- 刺绣和织物配件是否容易勾挂；
- 复杂纹样是否需要减线、分色或改用印刷；
- 效果图里的悬浮、发光和透明结构是否真的能实现。
- 是否需要昂贵开模、特殊电子件、液体密封或手工装配；若需要，是否有足够的设计价值。
- 六款中低至中成本产品是否占主体，高成本产品是否被控制在合理数量。
