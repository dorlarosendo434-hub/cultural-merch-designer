# 提示词与验收

## 产品概念图提示词骨架

为每个产品单独写提示词，至少包含：

```text
Use case: product-mockup
Asset type: 产品类型与定位
Input image: 原图在本次生成中的角色（如适用）
Primary request: 产品核心概念
Subject anchors: 必须保留的形态、比例、颜色、纹理、标志或道具
Design structure: 异形轮廓、浮雕、层级、活动件、光源或功能
Style/medium: 视觉风格与材料表现
Composition: 3:4竖版；上方约2/3呈现产品主体；下方约1/3为文字信息区
Text (verbatim): "文创名称｜<名称>"；"基础材质｜<主要材质＋基础工艺>"
Typography: 现代中文无衬线；名称中等字重、材质常规字重；较小字号；左对齐；宽松留白
Constraints: 身份锁定与生产约束
Avoid: 容易混淆的对象、俗套符号和禁止改动项
```

用户原图已经明确时，使用“preserve / exact / identity invariants”等表述锁定已有信息，不让生成模型重新设计角色。真实植物、动物和建筑则把核验得到的具体形态写入 `Subject anchors`。

## 固定出图版式

- 画布为 3:4 竖版，每款单独一张。
- 上方约 66%–70%：只呈现该款文创产品，保证主体完整、比例清楚；可带一个小型侧视或材质细节，但不能挤占主体。
- 下方约 30%–34%：纯色或低干扰信息区，与产品区有明确留白。
- 信息区固定两行，不添加价格、口号或长段说明：

```text
文创名称｜花桥流瀑陶瓷冰箱贴
基础材质｜釉面陶瓷＋背磁＋浅浮雕
```

- 名称应说明产品形态，材质只写基础构成和主要工艺。
- 默认采用类似思源黑体 / Noto Sans CJK 的现代中文无衬线风格；不使用宋体、仿宋、书法体、厚重衬线体或仿古标题字。
- 文字左对齐，距离画布左侧约 7%–9%；名称使用中等字重，材质使用常规字重，二者不做夸张粗细对比。
- 以约 1080 像素宽画布为参照，名称约 32–36 像素，材质约 28–32 像素；若模型不能理解像素值，则表述为“比常规产品海报说明文字小约 20%–25%，文字块只占信息区高度约一半”。
- 字色使用中性深灰或与产品协调的低饱和深色，避免纯黑、深棕大字压住画面；行距保持宽松，让底部信息区具有目录标签感而非宣传海报感。
- 中文必须准确可读；若图像模型产生错字、乱码、重复文字或裁切，保留产品不变，只返修底部信息区。

## 返修方式

一次只修一个主要问题，并重复所有不变量。例如：

- 只修正花型，保持产品结构、材质和构图不变；
- 只删除错误建筑，保留主体和层级关系；
- 只恢复原角色额纹与配饰，不改变脸型、服装和姿态；
- 只加粗连接件，不重画整件产品。

## 视觉验收

### 主体

- 与参考图或权威摄影对照后，关键特征是否同时存在；
- 是否被画成相似但错误的对象；
- 具体个体或原创 IP 是否仍具有唯一辨识度。

### 设计

- 外轮廓是否服务主体；
- 3D、浮雕或互动是否突出主体，而不是装饰噱头；
- 是否先从 48 种组合库建立候选池，而不是反复调用最熟悉的载体；
- 六款是否覆盖至少四个产品家族、四种主材和四种使用场景；
- 任意两款是否在产品家族、主材、工艺、互动和场景中至少有三个维度不同；
- 是否出现通用旅游纪念品套模板。
- 多色主体是否使用了经核验的真实色彩；是否六款无理由地锁成同一主色。

### 产品

- 正视图能否理解产品；
- 侧视图能否解释厚度与层次；
- 活动和开合是否有清楚结构；
- 工艺是否与材料相符；
- 是否存在断裂、过重、重心不稳或无法脱模的问题。
- 是否有足够多的低至中成本成熟品类；高成本概念款是否超过一款。

### 版式与文字

- 是否为 3:4 竖版；
- 产品是否占据上方约三分之二且完整可见；
- 底部约三分之一是否只包含名称和基础材质；
- 两行中文是否与当前产品完全一致、没有错字或乱码。
- 是否为现代无衬线字体、字号克制、字重不过粗、左对齐且有足够留白；若文字像海报标题一样抢眼，应只返修信息区。

## 交付判断

把结果分为三类：

- **可继续打样**：主体正确，结构基本可实现，只需工程细化；
- **概念成立但需返修**：创意有价值，但身份、尺寸或工艺存在明确问题；
- **淘汰**：主体错误、地域虚构、IP 走样或只是换载体印图。

不要把所有生成图都评价为成功。明确推荐主推款、传播款、低成本款和高客单款，并说明理由。
