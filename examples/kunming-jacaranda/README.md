# 昆明蓝楹花文创案例

本案例以昆明街头的蓝花楹（*Jacaranda mimosifolia*）为核验对象，保留蓝紫至淡紫色钟状/喇叭状花冠、圆锥花序、细密二回羽状叶，以及教场中路高大树冠相拥形成花廊的地域特征。

设计时禁止将主体画成紫藤、泡桐、三角梅、绣球、樱花或普通平面五瓣花，也不添加古建筑、宝塔、灯笼、祥云等无依据的地域符号。

## 推荐组合

- 旅游纪念主推：紫雾长街光栅明信片；
- 实用商品主推：春城蓝楹花冠折叠伞；
- 高质感主推：蓝楹花铃陶瓷线香座；
- 低成本引流：蓝楹花冠镂空书签、蓝楹枝梢珐琅胸针；
- 礼盒陈列：蓝楹花廊木质拼插小景。

## 打样提醒

- 光栅明信片需确定观看角度和两帧切换方向，控制街景重影。
- 黄铜书签需根据供应商最小蚀刻线宽加粗枝条连接。
- 陶瓷线香座需验证花筒脱模、烧成变形、香孔尺寸和灰槽清洁。
- 折叠伞应按真实伞片逐片拆图，让主枝走向与伞骨协调。
- 珐琅胸针建议控制在 35–45 mm，并为小尺寸生产重新减线。
- 木质拼插小景建议控制为 8–10 个零件，并测试 3 mm 与 5 mm 板材的稳定性。
