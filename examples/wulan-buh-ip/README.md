# 乌兰布和沙漠拟人 IP 文创案例

本案例以用户提供的原创角色图为唯一母版，不搜索或混入相似角色。设计时固定以下识别锚点：

- 深红色尖帽、金色宽边和青绿色卷云纹；
- 棕色蓬松短发、琥珀色大眼、额心红色旋纹；
- 红橙、赭色与深棕色叠穿服饰，宽松棕裤和金色鞋头；
- 青绿色珠饰、红青流苏、骆驼挂件；
- 双手捧着装有发光金沙的软木塞玻璃瓶。

## 推荐组合

- 主视觉：金沙瓶流沙亚克力冰箱贴；
- 实用商品：驼铃风帽提花零钱包；
- 文化互动：乌兰布和旅途印章套组；
- 低成本先行打样：半透明书签、三层立体明信片；
- 入门价格带：三件珐琅胸针组。

## 打样提醒

- 流沙冰箱贴需验证腔体密封、液体耐黄变、金沙沉降速度和运输耐压。
- 硅胶行李牌需简化过薄的小装饰，避免反复弯折后撕裂。
- 提花零钱包的五官建议采用织唛或刺绣补强，避免粗针距导致表情失真。
- 竹木手机支架建议测试 3 mm 与 5 mm 板材及不同手机壳的兼容性。
- 三层明信片应控制装配工序，并用半透明纸表现金沙瓶光感。
- 印章需重新绘制 25–35 mm 单色工艺稿，避免服装细纹糊版。
- 珐琅胸针需按供应商最细隔线要求简化局部纹样。
